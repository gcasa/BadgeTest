# BadgeTest

Small GNUstep/AppKit test application for exercising `NSDockTile` application
badge behavior.

The app opens a simple window that lets you set, increment, clear, and toggle
the badge label shown on the application's dock tile. It also displays the
current `NSDockTile` badge state for quick verification.

## Build

```sh
make
```

## Run

```sh
./BadgeTest.app/BadgeTest
```

## Clean

```sh
make clean
```
